# 새 .NET 기반 작업 규칙

## 모듈형 1.0.1 작업 인계

`Workspace.App`은 정식 모듈형 셸이며 엔진·리본·사이드바·뷰어는 별도 DLL입니다. 아래 TEST2 및 초기 단계 규칙은 이 구조의 현재 상태가 아니라 이력입니다. `ModularProductBuild=true`는 .NET 10을 대상으로 하며 정식 설치기는 `installer/v101/`에 있습니다. Electron 앱과 릴리스 채널은 건드리지 마세요. 제품명과 설치 파일명은 `더죤 PDF Workspace`, WPF 태그는 `wpf-v<version>`입니다. 배포 완료 여부는 실제 게시와 증빙을 확인해야 합니다.

실행 중 변경 영역 교체 및 실패 복구를 시험했지만 WPF 로드 컨텍스트의 실제 해제는 확인하지 못했습니다. 이전 모듈 파일은 보존합니다. 사용자 PDF는 복사본으로 시험하고 해시를 확인하세요. 신규 빌드·패키지 및 UI 검증과 실제 설치·게시 여부를 구분해 기록하세요.

## 다음 배포 방향 · 2026-11-17

사용자는 현재 시험판의 수정 사항을 먼저 모아 반영한 뒤, 메인폼과 열기 모달을 포함한 기본 설치판을 **1.0.1**로 만들고 필요한 기능 DLL은 별도 다운로드·설치하는 방향을 정했다. 이후 변경된 기능만 핀셋 패치하고 배포마다 제품 버전을 올린다. 기본 뼈대 수정은 앱 종료 후 패치하며, 기능 모듈은 가능한 한 앱 전체 종료 없이 해당 부분만 패치하는 것이 목표다. 현재 로더에서 실행 중 교체가 이미 가능하다고 가정하지 말고 모듈 해제·재로딩과 사용 중 처리, 호환성·복구를 설계·검증한다. 자세한 결정과 작업 순서, 미완성 작업 주의사항은 `docs/PLAN-1.0.1-MODULAR-DISTRIBUTION.md`를 먼저 확인한다. 이는 계획이며 구현·릴리즈 완료나 추가 게시 승인 자체를 뜻하지 않는다. 기존 Electron의 `v1.0.1`과 WPF 제품 버전·태그를 혼동하지 않는다.

작업 기록에는 사용자 방향 변경으로 중단된 **미완성·미검증 WPF 업데이트/설치기 코드**가 보존되어 있다. 일반 실행에서 해당 업데이트 초안은 시작하지 않는다. 자동 업데이트가 완성됐다고 간주하거나 이를 무조건 이어서 릴리즈하지 말고, 새 모듈형 계획과 사용자 수정 목록을 기준으로 재검토한다. 작업물 임의 삭제 금지.

## 현재 구현 상태 · 2026-11-17

현재 앱은 샘플 전용이 아닙니다. 빈 화면 시작, 실제 PDF 열기/Ctrl+O, 메인 캔버스와 사이드바, 선택 페이지 회전·삭제·순서 변경·추출, 병합, 실행 취소/다시 실행, 저장/다른 이름으로 저장(확인 포함)이 통합되어 있습니다. TEST2는 기존 시험판과 별도 설치되도록 구성했습니다. 제한은 단일 문서, 최초 24쪽 축소판 생성 후 나머지는 탐색 시 생성, 텍스트 편집·자르기·주석·인쇄 미지원입니다. 글꼴 충실도와 실제 네이티브 입력 조작은 검증되지 않았습니다. 위 상태를 과거 단계 설명이나 검증 이력과 혼동하지 마세요.

- 이 폴더는 새 출발입니다. 기존 Electron/TypeScript 코드는 참고용이며 자동 포팅하지 않습니다.
- 현재 `README.md`와 `docs/WORKSPACE-UX.md`의 범위·다음 단계·검증 경계를 먼저 읽습니다. 기능 이름·빈 버튼만 추가해서 구현 완료로 취급하지 않습니다.
- 메인 화면은 조립·표시만 담당합니다. 공통 계약/모듈 실행부에 WPF나 PDF 라이브러리 의존성을 넣지 않습니다.
- 모듈의 화면과 처리 로직을 분리하고, 호출은 공통 명령 실행부를 통과시킵니다. API 버전과 모듈/명령 ID를 안정적으로 유지합니다.
- 초기 DLL은 신뢰하는 자체 빌드만 명시적 목록으로 로드합니다. 외부 DLL 자동 검색·다운로드, 핫스왑, 보안 샌드박스 구현을 추정하지 않습니다.
- 초기 샘플 전용 단계의 메모리 내 페이지 관리 설명은 과거 상태입니다. 실제 PDF 열기·페이지 작업·저장 흐름은 현재 구현되어 있습니다. 세부 범위와 제한은 위 날짜 표시를 따르며, 지원되지 않는 기능이나 미검증된 보존·표시 특성을 추정하지 않습니다.
- 읽기 전용 보기와 편집·저장 단계를 분리합니다. 기존의 이미지화 텍스트 교체를 원본 텍스트 편집으로 이식하거나 안내하지 않습니다.
- 현재 SDK 9.0.308은 설치된 환경을 이용한 기초 검증용입니다. 배포 전 지원 중인 LTS 기준을 확정해야 합니다. SDK 설치나 외부 의존성 도입은 별도 범위입니다.
- `dotnet build Workspace.sln`, `Workspace.Checks`, 셸 `--smoke`로 검사합니다. 실제 GUI 입력·물리 DPI·PDF 입출력은 별도 검증입니다.
- 새 코드와 README만 수정합니다. 이전 앱·릴리즈·기본 PDF 연결은 요청 없이 변경하지 않습니다. `bin/obj`와 검사 출력은 커밋하지 않습니다.
- 모듈 하나를 완성된 흐름으로 검증한 뒤 다음 기능을 추가합니다. 당장 사용하지 않는 추상화·플러그인 마켓·클라우드는 만들지 않습니다.
