# 다음 버전 작업 목록

1. **본문 스크롤과 축소판 선택 동기화**: 사용자가 본문을 스크롤해 다른 페이지로 이동해도 축소판 선택이 그대로 남는 문제가 보고됐다. 현재 보이는 페이지와 축소판 선택이 자연스럽게 연동되도록 수정하고, 연속 스크롤 및 직접 축소판 선택을 실제 앱에서 확인한다.
2. **시작 시 최대화**: 프로그램을 시작할 때 창이 항상 최대화 상태로 열리도록 수정하고 실제 실행 화면에서 확인한다.
3. **파일·홈 메뉴의 열기/저장 중복 정리**: 열기와 저장은 파일 메뉴에 두고, 홈 메뉴에서 중복 버튼을 제거한다.
4. **실행 취소 메뉴 위치 정리**: 실행 취소는 편집 메뉴에 배치하도록 메뉴 구성을 정리한다.

위 항목은 다음 버전의 미구현 작업이다. 1.0.1에 수정이 반영되거나 새 버전이 배포된 것은 아니다.
